### Improved PRM Algorithm for Multi-Drone Motion Planning

The following pseudocode describes the BiRRT.

```python


BiRRT(sim, max_iterations, step_size):
    # Input:
    #   sim – MultiDrone environment object, providing is_valid(q) and motion_valid(q1, q2)
    #   max_iterations – maximum number of iterations
    #   step_size – maximum step size when extending toward a sampled point
    #
    # Output:
    #   A path from start to goal if found, otherwise return failure

    # ---------------------------
    # 1. Initialization
    # ---------------------------
    Tree_A ← Initialize tree with root node = sim.initial_configuration   # Start tree (from start configuration)
    Tree_B ← Initialize tree with root node = sim.goal_positions          # Goal tree (from goal configuration)

    # ---------------------------
    # 2. Iterative Expansion
    # ---------------------------
    for i in 1 → max_iterations:
        
        q_rand ← UniformSample(sim.bounds, sim.N)  
        # Randomly sample a configuration q_rand in the configuration space (C-space)

        # --- Step A: Expand Tree_A ---
        q_near_A ← Nearest(Tree_A, q_rand)             
        # Find the nearest node in Tree_A to q_rand

        q_new_A ← Steer(q_near_A, q_rand, step_size)   
        # Move one step from q_near_A toward q_rand (step length ≤ step_size)

        if sim.motion_valid(q_near_A, q_new_A):         
            # Check if the motion from q_near_A to q_new_A is collision-free
            AddNode(Tree_A, q_new_A, parent = q_near_A) 
            # Add the new node into Tree_A, record its parent

            # --- Step B: Try expanding Tree_B toward q_new_A ---
            q_near_B ← Nearest(Tree_B, q_new_A)          
            # Find the nearest node in Tree_B to q_new_A

            q_new_B ← Steer(q_near_B, q_new_A, step_size)
            # Move one step from q_near_B toward q_new_A

            if sim.motion_valid(q_near_B, q_new_B):
                # If this motion is valid (collision-free)
                AddNode(Tree_B, q_new_B, parent = q_near_B)
                # Add the new node into Tree_B

                if Distance(q_new_A, q_new_B) < step_size:
                    # If the new nodes of both trees are close enough
                    path_A ← ExtractPath(Tree_A, root = start, leaf = q_new_A)
                    path_B ← ExtractPath(Tree_B, root = goal, leaf = q_new_B)
                    path_B ← Reverse(path_B)  # Reverse the path from the goal tree
                    return Concatenate(path_A, path_B)
                    # Concatenate both paths to obtain the full solution

        # ---------------------------
        # 3. Swap the roles of the trees
        # ---------------------------
        Swap(Tree_A, Tree_B)
        # Alternate between growing the start tree and the goal tree

    # ---------------------------
    # 4. If no path is found after all iterations
    # ---------------------------
    return Failure
