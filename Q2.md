### Improved PRM Algorithm for Multi-Drone Motion Planning

The following pseudocode describes the improved PRM with *bridge sampling* and *visibility checks*, designed to handle *narrow passages*, *bug traps*, and *cluttered obstacles*.  

```python
function ImprovedPRM(num_samples, k_neighbors, environment, r, K, start, goal):

    # num_samples: maximum number of samples
    # k_neighbors: number of nearest neighbors for PRM edges
    # environment: obstacle representation
    # r: drone radius
    # K: number of drones
    # start, goal: start and goal configurations

    V = []   # node set
    E = []   # edge set

    # Step 1: Sampling nodes (Bridge Sampling + Visibility PRM)
    while len(V) < num_samples:

        # 1.1 choose sampling strategy
        if RandomChoice([0.3, 0.7]) == "bridge":   # 30% bridge sampling
            q = BridgeSample(K, environment, r)
        else:
            q = SampleConfiguration(K)

        # 1.2 collision check
        if not IsCollisionFree(q, environment, r):
            continue

        # 1.3 visibility test (Visibility PRM)
        if not IsRepresentative(q, V, environment, r):
            continue

        # 1.4 valid sample → add to node set
        V.append(q)

    # Step 2: Build roadmap
    for q in V:
        neighbors = NearestNeighbors(q, V, k_neighbors)
        for q_near in neighbors:
            if LocalPlanner(q, q_near, environment, r):
                E.append((q, q_near))

    # Step 3: Graph search (A* / Dijkstra)
    path = GraphSearch(V, E, start, goal)

    return path

#Helper Function
function SampleConfiguration(K):
    # Uniformly sample a random configuration for K drones
    # Output: np.ndarray of shape (K, 3) → [x, y, z] positions
    return random_positions_in_free_space(K)

function IsCollisionFree(q, environment, r):
    # Check if configuration q is collision-free
    # Ensure each drone does not intersect with obstacles or other drones
    return not collides_with_obstacles(q, environment, r)

function BridgeSample(K, environment, r):
    # Bridge test for narrow passages:
    # 1. Randomly sample two colliding points q1, q2
    # 2. If both collide, compute midpoint q_mid
    # 3. If q_mid is collision-free → return q_mid
    # Otherwise, return None
    return midpoint_if_valid(q1, q2, environment, r)

function IsRepresentative(q, V, environment, r):
    # Visibility test to reduce redundant samples
    # If q can already "see" too many nodes in V, reject it
    visible_count = 0
    for v in V:
        if LocalPlanner(q, v, environment, r):
            visible_count += 1
    return (visible_count < threshold)

function NearestNeighbors(q, V, k):
    # Return k closest nodes in V to q
    return k_smallest_distance_nodes(q, V, k)

function LocalPlanner(q, v, environment, r):
    # Check if straight-line path between q and v is collision-free
    # Simulate motion of drones along interpolated path
    return no_collision_along_path(q, v, environment, r)

function GraphSearch(V, E, start, goal):
    # Standard shortest-path search (e.g., A* or Dijkstra)
    return shortest_path(V, E, start, goal)










BiRRT(sim, max_iterations, step_size):
    # Input:
    #   sim – MultiDrone environment object, providing is_valid(q) and motion_valid(q1, q2)
    #   max_iterations – maximum number of iterations
    #   step_size – maximum step size when extending toward a sampled point
    #
    # Output:
    #   A path from start to goal if found, otherwise return failure

    # ---------------------------
    # 1. Initialization
    # ---------------------------
    Tree_A ← Initialize tree with root node = sim.initial_configuration   # Start tree (from start configuration)
    Tree_B ← Initialize tree with root node = sim.goal_positions          # Goal tree (from goal configuration)

    # ---------------------------
    # 2. Iterative Expansion
    # ---------------------------
    for i in 1 → max_iterations:
        
        q_rand ← UniformSample(sim.bounds, sim.N)  
        # Randomly sample a configuration q_rand in the configuration space (C-space)

        # --- Step A: Expand Tree_A ---
        q_near_A ← Nearest(Tree_A, q_rand)             
        # Find the nearest node in Tree_A to q_rand

        q_new_A ← Steer(q_near_A, q_rand, step_size)   
        # Move one step from q_near_A toward q_rand (step length ≤ step_size)

        if sim.motion_valid(q_near_A, q_new_A):         
            # Check if the motion from q_near_A to q_new_A is collision-free
            AddNode(Tree_A, q_new_A, parent = q_near_A) 
            # Add the new node into Tree_A, record its parent

            # --- Step B: Try expanding Tree_B toward q_new_A ---
            q_near_B ← Nearest(Tree_B, q_new_A)          
            # Find the nearest node in Tree_B to q_new_A

            q_new_B ← Steer(q_near_B, q_new_A, step_size)
            # Move one step from q_near_B toward q_new_A

            if sim.motion_valid(q_near_B, q_new_B):
                # If this motion is valid (collision-free)
                AddNode(Tree_B, q_new_B, parent = q_near_B)
                # Add the new node into Tree_B

                if Distance(q_new_A, q_new_B) < step_size:
                    # If the new nodes of both trees are close enough
                    path_A ← ExtractPath(Tree_A, root = start, leaf = q_new_A)
                    path_B ← ExtractPath(Tree_B, root = goal, leaf = q_new_B)
                    path_B ← Reverse(path_B)  # Reverse the path from the goal tree
                    return Concatenate(path_A, path_B)
                    # Concatenate both paths to obtain the full solution

        # ---------------------------
        # 3. Swap the roles of the trees
        # ---------------------------
        Swap(Tree_A, Tree_B)
        # Alternate between growing the start tree and the goal tree

    # ---------------------------
    # 4. If no path is found after all iterations
    # ---------------------------
    return Failure
